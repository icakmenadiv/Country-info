# Country-info

OCIS 국별환경의 **갱신 우선순위**를 확인하기 위한 경량 대시보드입니다.

## 핵심 컨셉
기존 OCIS 본문이나 값을 저장·복제하지 않습니다.

저장하는 정보는 최소한으로 제한합니다.
- 국가
- 항목명
- OCIS 최근 수정일(`ocis_updated_at`)
- OCIS 국가/항목 코드(`ntnCd`, `tocCd`) — 확인되는 경우
- 원문 링크 — 확인되는 경우

이 메타데이터만으로 어느 국가와 어떤 항목을 먼저 최신화할지 추천합니다.

## 추천 규칙
1. 대상은 **유럽 8개국 + 중앙아시아 5개국 = 13개국**입니다.
2. 국가별 항목 중 가장 오래된 `ocis_updated_at`을 구합니다.
3. 그 날짜가 가장 오래된 국가를 **다음 추천 국가**로 선정합니다.
4. 해당 국가에서 `ocis_updated_at`이 오래된 순으로 **최대 5개 항목**을 추천합니다.
5. 본문 내용, 기존값, 검증일, UPDATE/KEEP/REVIEW 상태는 추천에 사용하지 않습니다.
6. 수정일이 없는 항목은 날짜가 확인될 때까지 `날짜 미확인`으로 별도 표시하고 자동 추천 순위에서는 제외합니다.

## PoC 대상국
### 유럽
러시아, 루마니아, 영국, 우크라이나, 조지아, 체코, 폴란드, 헝가리

### 중앙아시아
우즈베키스탄, 카자흐스탄, 키르기스스탄, 타지키스탄, 투르크메니스탄

## 저장 구조
- `index.html` : 대시보드
- `styles.css` : 화면 스타일
- `app.js` : 추천/정렬 로직
- `data/state.json` : 대상국 목록
- `data/updates.json` : OCIS 항목별 최근 수정일 메타데이터
- `config/policy.json` : 추천 규칙
- `PROMPT.md` : ChatGPT에서 저장소를 사용할 때의 실행 규칙

## `data/updates.json` 예시
```json
{
  "country_code": "UZB",
  "country_name": "우즈베키스탄",
  "region": "Central Asia",
  "ntnCd": "...",
  "tocCd": "...",
  "title": "건설업제도",
  "ocis_updated_at": "2022-05-10",
  "page_url": "https://ocis.go.kr/environment/..."
}
```

## 기본 사용 명령
- `Country-info 저장소 기준으로 국별환경 갱신 후보 5개 추천해줘`
- `Country-info 저장소 기준으로 우즈베키스탄 갱신 후보 5개 보여줘`
- `Country-info 저장소의 국가별 최신성 현황 보여줘`

## 의도적으로 하지 않는 것
- OCIS 기존 본문 전체 Import
- 기존값 저장
- GPT가 기존값과 최신값을 자동 비교
- UPDATE / KEEP / REVIEW 판정 누적
- 미반영 제안 관리

대시보드의 역할은 **오래된 정보가 어디에 있는지 빠르게 찾는 것**까지입니다. 실제 최신화 조사와 문안 작성은 추천된 항목을 대상으로 별도로 수행합니다.
