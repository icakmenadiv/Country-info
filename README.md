# Country-info

OCIS 국별환경의 **갱신 우선순위**를 확인하기 위한 경량 대시보드입니다.

## 핵심 컨셉
기존 OCIS 본문이나 값을 저장·복제하지 않습니다.

저장하는 정보는 최소한으로 제한합니다.
- 국가
- 과거/현재 항목명
- OCIS 최근 수정일(`ocis_updated_at`)
- 현재 OCIS 운영 구조(`active / merged / retired / unknown`)
- 통합된 경우 상위 운영 항목(`merged_into`)
- OCIS 국가/항목 코드(`ntnCd`, `tocCd`) — 확인되는 경우
- 원문 링크 — 확인되는 경우

## 중요한 운영 원칙
엑셀에 존재하는 항목이 모두 현재 OCIS에서 독립적으로 운영되는 것은 아닙니다.

2026-09-07 우즈베키스탄(`ntnCd=299`)을 기준으로 현재 OCIS 전체 항목체계를 직접 확인한 결과, 국가별 국별환경은 동일한 공통 항목체계를 사용하며 과거 엑셀의 83개 제목은 다음과 같이 분류됩니다.
- `active` 69개: 현재 독립 상세페이지로 운영
- `merged` 11개: 상위 항목 본문에 통합
- `retired` 3개: 현재 메뉴에서 독립 항목으로 확인되지 않음

### 통합된 일반현황 세부항목
- `일반현황 > 정치 > 약사/국가제도/정부요인/최근 정치동향/외교노선, 지역협의체 참여` → `일반현황 > 정치`
- `일반현황 > 경제 > 주요경제지표/최근 경제동향/경제개발계획` → `일반현황 > 경제`
- `일반현황 > 우리나라와의 관계 > 정치/외교/무역/주재기관` → `일반현황 > 우리나라와의 관계`

반면 인프라 건설시장, 플랜트 건설시장, 건설업 제도, 투자·조세·금융·보험·노동·출입국, 공사수행환경, 우리나라 진출현황의 대부분 세부항목은 현재도 각각 독립 상세페이지로 운영됩니다.

따라서 **추천 전에 공통 현행 OCIS 항목체계를 적용하고, active 항목만 자동 추천**합니다.

## 추천 규칙
1. 대상은 **유럽 8개국 + 중앙아시아 5개국 = 13개국**입니다.
2. `data/structure.json`의 공통 현행 OCIS 항목체계를 13개국에 적용합니다.
3. `merged`와 `retired` 항목은 오래된 수정일이 있어도 자동 추천에서 제외합니다.
4. `active` 항목만 대상으로 국가별 가장 오래된 `ocis_updated_at`을 구합니다.
5. 그 날짜가 가장 오래된 국가를 **다음 추천 국가**로 선정합니다.
6. 해당 국가의 active 항목을 `ocis_updated_at` 오래된 순으로 최대 5개 추천합니다.
7. 기존 엑셀 날짜 데이터는 보존하되, 현재 독립 운영되지 않는 과거 항목의 날짜는 추천 순위에 영향을 주지 않습니다.

## 구조 검증 기준
공통 항목체계는 2026-09-07 우즈베키스탄 OCIS 화면에서 직접 확인했습니다. 국가별 메뉴가 동일한 체계로 운영되므로 이를 13개 대상국에 공통 적용합니다.

향후 OCIS 항목체계 자체가 변경된 것이 발견되면 다른 국가별 예외를 먼저 만들기보다 공통 구조(`data/structure.json > common`)를 갱신합니다. 특정 국가에서만 실제 예외가 확인되는 경우에만 국가별 override를 추가합니다.

## PoC 대상국
### 유럽
러시아, 루마니아, 영국, 우크라이나, 조지아, 체코, 폴란드, 헝가리

### 중앙아시아
우즈베키스탄, 카자흐스탄, 키르기스스탄, 타지키스탄, 투르크메니스탄

## 저장 구조
- `index.html` : 대시보드
- `styles.css` : 화면 스타일
- `app.js` : 구조 판정 + 추천/정렬 로직
- `data/state.json` : 대상국 목록
- `data/catalog.json` : 엑셀에서 가져온 과거 OCIS 항목별 수정일 메타데이터
- `data/structure.json` : 현행 공통 OCIS 항목체계와 merged/retired 매핑
- `config/policy.json` : 추천 규칙
- `PROMPT.md` : ChatGPT에서 저장소를 사용할 때의 실행 규칙

## 기본 사용 명령
- `Country-info 저장소 기준으로 현재 OCIS 운영 구조를 반영해 국별환경 갱신 후보 5개 추천해줘`
- `Country-info 저장소 기준으로 우즈베키스탄 갱신 후보 5개 보여줘`
- `Country-info 저장소의 국가별 최신성 현황 보여줘`

## 의도적으로 하지 않는 것
- OCIS 기존 본문 전체 Import
- 기존값 저장
- GPT가 기존값과 최신값을 자동 비교
- UPDATE / KEEP / REVIEW 판정 누적
- 미반영 제안 관리

대시보드의 역할은 **현재 실제 운영되는 항목 중 오래된 정보가 어디에 있는지 정확히 찾는 것**까지입니다. 실제 최신화 조사와 문안 작성은 추천된 active 항목을 대상으로 별도로 수행합니다.
