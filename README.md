# Country-info

OCIS 국별환경의 **갱신 우선순위**를 확인하기 위한 경량 대시보드입니다.

## 핵심 컨셉
기존 OCIS 본문이나 값을 저장·복제하지 않습니다.

저장하는 정보는 최소한으로 제한합니다.
- 국가
- 과거/현재 항목명
- OCIS 최근 수정일(`ocis_updated_at`)
- 현재 OCIS 운영 구조(`active / merged / retired / unknown`)
- 통합된 경우 상위 운영 항목(`merged_into`)
- OCIS 국가/항목 코드(`ntnCd`, `tocCd`) — 확인되는 경우
- 원문 링크 — 확인되는 경우

## 중요한 운영 원칙
엑셀에 존재하는 항목이 모두 현재 OCIS에서 독립적으로 운영되는 것은 아닙니다.

과거에는 세분화되어 있던 항목이 현재 OCIS에서는 하나의 상위 항목 본문으로 통합된 사례가 있습니다.
예: 우즈베키스탄의 과거 `일반현황 > 경제 > 주요경제지표`, `최근 경제동향`, `경제개발계획`은 현재 OCIS에서 독립 탭이 아니라 `일반현황 > 경제` 본문에 통합되어 있습니다.

따라서 **추천 전에 현재 OCIS 독립 운영 여부를 우선 확인**합니다.

상태는 다음과 같이 관리합니다.
- `active`: 현재 OCIS에서 독립 항목으로 운영 중 → 자동 추천 대상
- `merged`: 상위 active 항목의 본문으로 통합 → 자동 추천 제외
- `retired`: 폐지된 항목 → 자동 추천 제외
- `unknown`: 현재 구조 미확인 → 자동 추천 제외, 구조 확인 필요로 표시

## 추천 규칙
1. 대상은 **유럽 8개국 + 중앙아시아 5개국 = 13개국**입니다.
2. `data/structure.json`에서 현재 OCIS 구조가 확인된 국가와 `active` 항목을 확인합니다.
3. 과거 세부항목이 현재 상위 항목으로 통합된 경우 `merged`로 처리하고 자동 추천에서 제외합니다.
4. `active` 항목만 대상으로 국가별 가장 오래된 `ocis_updated_at`을 구합니다.
5. 그 날짜가 가장 오래된 국가를 **다음 추천 국가**로 선정합니다.
6. 해당 국가의 `active` 항목을 `ocis_updated_at` 오래된 순으로 최대 5개 추천합니다.
7. `unknown` 국가는 현재 OCIS 구조가 확인될 때까지 자동 추천에서 제외합니다.
8. 기존 엑셀의 날짜 데이터는 보존하지만, 현재 운영되지 않는 과거 세부항목의 오래된 날짜는 추천 순위에 영향을 주지 않습니다.

## 현재 확인된 구조
### 우즈베키스탄
2026-09-07 기준 OCIS 현재 내비게이션을 직접 확인했습니다.

예시:
- `일반현황 > 경제` → `active`
- `일반현황 > 경제 > 주요경제지표` → `merged`
- `일반현황 > 경제 > 최근 경제동향` → `merged`
- `일반현황 > 경제 > 경제개발계획` → `merged`

같은 원리로 현재 OCIS에서 실제로 노출되는 독립 중분류를 `active_titles`로 관리합니다.

## PoC 대상국
### 유럽
러시아, 루마니아, 영국, 우크라이나, 조지아, 체코, 폴란드, 헝가리

## 저장 구조
- `index.html` : 대시보드
- `styles.css` : 화면 스타일
- `app.js` : 구조 판정 + 추천/정렬 로직
- `data/state.json` : 대상국 목록
- `data/catalog.json` : 엑셀에서 가져온 과거 OCIS 항목별 수정일 메타데이터
- `data/structure.json` : 현재 OCIS 독립 운영 구조 확인 결과
- `config/policy.json` : 추천 규칙
- `PROMPT.md` : ChatGPT에서 저장소를 사용할 때의 실행 규칙

## 기본 사용 명령
- `Country-info 저장소 기준으로 현재 OCIS 운영 구조를 반영해 국별환경 갱신 후보 5개 추천해줘`
- `Country-info 저장소 기준으로 우즈베키스탄 갱신 후보 5개 보여줘`
- `Country-info 저장소의 국가별 최신성 현황 보여줘`

## 구조 확인 워크플로
1. 해당 국가 OCIS 페이지를 직접 확인합니다.
2. 현재 화면에 독립적으로 노출되는 항목명을 `active_titles`에 기록합니다.
3. 기존 엑셀의 더 세부적인 하위 항목은 자동으로 `merged` 판정합니다.
4. 화면에서도 사라졌고 상위 항목에도 포함되지 않는 것이 확인되면 `retired_titles`에 기록합니다.
5. 확인 전 국가는 `unknown` 상태로 두고 자동 추천하지 않습니다.

## 의도적으로 하지 않는 것
- OCIS 기존 본문 전체 Import
- 기존값 저장
- GPT가 기존값과 최신값을 자동 비교
- UPDATE / KEEP / REVIEW 판정 누적
- 미반영 제안 관리

대시보드의 역할은 **현재 실제 운영되는 항목 중 오래된 정보가 어디에 있는지 정확히 찾는 것**까지입니다. 실제 최신화 조사와 문안 작성은 추천된 active 항목을 대상으로 별도로 수행합니다.
